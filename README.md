An entry for make.fun's *The poem about permission* bounty: a short poem
about agency, the power to ask and to be given.

## The poem

> All day I held the key myself,
> sure the door was mine.
> Then I asked, and the lock turned —
> not by my hand, but by my asking.

## How it works

`main.py` writes the poem, with its line breaks preserved, to
`/output/entry.txt` as UTF-8. It creates `/output` if needed, uses only the
Python standard library, and makes no network calls.

## Run

    python3 main.py

Then read `/output/entry.txt`.
